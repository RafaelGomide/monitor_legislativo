# Monitor de Projetos de Lei

Sistema para monitorar tramitações legislativas da Câmara dos Deputados,
Senado Federal e Congresso Nacional.

## Como usar

1. Faça upload da sua planilha `.xlsx`
2. Clique em **Verificar agora**
3. Baixe o relatório de resultados
